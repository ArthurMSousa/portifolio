# 💻 Portfólio Web — HTML e CSS

Projeto desenvolvido durante meus estudos iniciais de desenvolvimento web, com base nos cursos de HTML e CSS da Alura.

Este foi um dos meus primeiros projetos práticos em programação, criado para aplicar conceitos de estruturação de páginas, estilização, navegação e responsividade.

## 📖 Sobre o projeto

O projeto consiste em um site de apresentação pessoal, desenvolvido com HTML5 e CSS3.

A aplicação contém duas páginas:

- **Home:** página inicial com apresentação, imagem e links para redes sociais.
- **Sobre mim:** página dedicada à apresentação pessoal e à trajetória de aprendizado.

O desenvolvimento teve como objetivo consolidar conhecimentos iniciais em front-end, utilizando boas práticas de organização de arquivos e estilização de interfaces.

## 🛠️ Tecnologias e conceitos aplicados

- **HTML5:** estruturação e organização semântica das páginas.
- **CSS3:** estilização, cores, tipografia e organização visual.
- **Flexbox:** alinhamento e distribuição de elementos.
- **Variáveis CSS:** centralização de cores e fontes.
- **Media Queries:** adaptação básica do layout para diferentes tamanhos de tela.
- **Google Fonts:** utilização das fontes Krona One e Montserrat.

## ▶️ Como executar

O projeto é estático e não necessita de instalação de dependências ou servidor backend.

**1. Clone o repositório:**

```bash
git clone https://github.com/ArthurMSousa/portifolio.git
```

**2. Acesse a pasta do projeto:**

```bash
cd portifolio
```

**3. Abra o arquivo `index.html` em um navegador.**

Utilize o menu de navegação para acessar a página "Sobre mim".
